提交文件名为 **`学号_姓名_lab05.zip`**。训练和评估在学校107平台完成，具体收件渠道与截止时间以课程通知为准。下载的课程材料包用于学习，请另建提交目录整理自己的成果。

## 1. 提交前需要完成什么

- 补全 `operator_exercises.py` 和 `student_encoder.py`，在本地CPU（Central Processing Unit，中央处理器）环境完成卷积、激活、池化与编码器检查，将结果记入报告。
- 运行基础编码器与一个改进编码器，使用提供的同一解码器，保持数据划分、分辨率、种子和训练预算一致，记录主要改动。
- 根据验证集选择最终模型，再运行完整测试集评估，报告选定模型的最终表现。
- 根据 `report-template.md` 写报告，导出为 `report.pdf`。包括层尺寸与参数表、训练曲线、对照结果、至少3个成功和3个失败样例及原因分析。
- U-Net 为独立选做，由学生根据结构图自行编写。选做者一并提交新增源码、检查结果、对照记录与理论分析。

这里的 IoU（Intersection over Union，交并比）与 Dice 均为逐图前景指标再取平均。统一使用128×128评估网格和0.5概率阈值，忽略原始标注值3。成绩使用本人选定模型在全部3669张测试图像上的结果。

基础版与改进版作业先执行CPU模型检查，再由脚本指定GPU（Graphics Processing Unit，图形处理器）训练。模型检查输出与训练记录保存在同一份Slurm `.out` 日志中，随实验记录提交。本地与平台沿用同一份模型实现。

## 3. README.md 应写清什么

请写入姓名学号、Python与PyTorch版本、运行设备、各模型对应的107作业编号、最终选中哪组及理由、数据来源和放置位置、各实验的完整命令，以及新增或修改了哪些文件。同时记录参考资料和使用的工具。

从提交目录根部可按下面的命令复核保存的最终模型。把 `--data-dir` 换成评估机器上包含 `splits.json` 与 `oxford-iiit-pet/` 的目录；在107平台通过计算作业执行评估。

```bash
python selected/source/evaluate.py \
  --checkpoint selected/best.pt \
  --data-dir /实际数据路径/data \
  --device cuda --split test --output verify-test-01
```

`verify-test-01` 为本次复核新建的输出目录。复核结果用于比较模型保存前后的评估一致性。原始 `run.json` 中的训练路径保留原样，在 README 中补充新机器的路径映射即可。
