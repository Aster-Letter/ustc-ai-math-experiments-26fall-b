## 课前准备

- 按照[实验 01 手册](实验01_Python环境与基础入门/实验01_实验手册.md)配置 Python 环境，安装所需的库，并试运行配套程序。建议提前完成，避免课堂上集中下载。
- 熟悉 Python 的基本语法，学会运行和修改 `.py` 文件。可以结合 [Python 基础练习](实验01_Python环境与基础入门/code/practice.ipynb)和[语法带练](实验02_信息熵与决策树/Python语法带练.md)练习。
- 下载材料后完整解压，保留代码与数据的目录结构。实验 01 也可直接下载[学生材料包](downloads/lab01-python-basics-26fall-B.zip)。

## 作业提交

提交平台和截止时间以课程通知为准，具体文件要求见各次实验说明。

- **实验 01**：提交 `学号_姓名_lab01.zip`，包含完成的代码、运行所需的辅助模块与数据，以及 `report.pdf`。目录结构和报告要求见[提交说明](实验01_Python环境与基础入门/实验01_实验手册.md#提交成果)。Python 环境、安装包和缓存无需提交。
- **实验 02**：按讲义和代码中的 T1–T7 完成决策树练习，当前材料不另行要求提交报告。
- **实验 03**：提交 `学号_姓名_lab03.zip`，包含已完成代码、运行所需辅助模块与数据，以及 `report.pdf`。报告采用“实验概况—C0–C7 实现与验证—综合实验结果—结果分析与总结”四部分，见[报告与提交说明](实验03_逻辑回归与大学排名分类/README.md#实验报告与提交)。

实验 01 提交前，请运行配套检查程序，并将压缩包解压到其他位置试运行，确认所需文件齐全。遇到未解决的问题，在报告中说明已完成的部分和具体问题。
