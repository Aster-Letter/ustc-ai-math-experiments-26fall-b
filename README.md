# 人工智能数学原理与算法 B：课程实验

中国科学技术大学 人工智能与数据科学学院，2026 年秋季（课程编号：AI1001B.03）。

- 主讲：钟志诚
- 整理：曾有成、史睿铭、胡泷

本仓库用于发布课程实验的讲义、代码和数据。

## 课前准备

- 按照[实验 01 手册](实验01_Python环境与基础入门/实验01_实验手册.md)配置 Python 环境，安装所需的库，并试运行配套程序。建议提前完成，避免课堂上集中下载。
- 熟悉 Python 的基本语法，学会运行和修改 `.py` 文件。可以结合 [Python 基础练习](实验01_Python环境与基础入门/code/practice.ipynb)和[语法带练](实验02_信息熵与决策树/Python语法带练.md)练习。
- 下载材料后完整解压，保留代码与数据的目录结构。

## 作业提交

提交平台和截止时间以课程通知为准，具体文件要求见各次实验说明。

- **实验 01**：提交 `学号_姓名_lab01.zip`，包含完成的代码、运行所需的辅助模块与数据，以及 `report.pdf`。目录结构和报告要求见[提交说明](实验01_Python环境与基础入门/实验01_实验手册.md#提交成果)。Python 环境、安装包和缓存无需提交。
- **实验 02**：按讲义和代码中的 T1–T7 完成决策树练习，不组织提交。
- **实验 03**：提交 `学号_姓名_lab03.zip`，包含已完成代码、运行所需辅助模块与数据，以及 `report.pdf`。报告采用“实验概况—C0–C7 实现与验证—综合实验结果—结果分析与总结”四部分，见[报告与提交说明](实验03_逻辑回归与大学排名分类/README.md#实验报告与提交)。
- **实验 04**：工具配置与自主学习，不要求提交。
- **实验 05**：在本地NVIDIA GPU或107平台训练与评估，提交 `学号_姓名_lab05.zip`，包含代码、报告、选定权重、训练/评估记录与运行日志，见[提交与打包说明](实验05_宠物主体分割与小型UNet/提交与打包说明.md)。
- **实验 06**：实现小型字符语言模型，在107平台通过Slurm完成中文古诗训练、生成与测试，提交代码、报告、选定权重、四份生成对照和作业日志，见[实验说明](实验06_TinyGPT实现与文本生成/README.md)。
- **课程大作业**：可个人完成或组队，原则上每组最多3人；选择质谱分子识别统一课题，或申请经助教确认的自选课题。11月9日23:59前按课程群配图登记；最终ZIP于11月24日晚前由小组代表提交Bb，准确DDL以平台或后续公告为准。汇报暂定11月下旬至12月上旬，每组5分钟加最多2分钟问答；演示文件最晚于本组汇报前的周日提交。见[共同安排与统一题指南](大作业_质谱分子识别/README.md)。
