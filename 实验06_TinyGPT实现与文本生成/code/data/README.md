# 五言诗教学子集（THU-CCPC）

来源：[THUNLP-AIPoet/Datasets](https://github.com/THUNLP-AIPoet/Datasets/tree/master/CCPC)，固定提交 `0a53d6a29c1dc5e3f69de446e8c94b28b3b2437b`。THU-CCPC（THU Chinese Classical Poetry Corpus，清华中国古典诗歌语料库）上游声明仅供学术使用；引用Guo等2019年Jiuge论文，见 `SOURCE-TERMS.txt`。数据使用遵循上游学术用途声明，代码许可另列于实验目录。

筛选四句、每句五个基本汉字的正文，统一增加“，。，。”标点、逐句换行及篇间双换行。保留源字形（此子集以简体为主），模型输入为诗歌正文，标题、作者和关键词不参与训练；筛选依据为句数与字数，平仄和押韵需另行分析。

保持官方训练/验证/测试归属，按测试、验证、训练的优先级对20字正文做完全重复去重，本次重复移除数为0。筛选后的集合规模见下表，比例并非8:1:1。划分沿用官方归属，同一作者、近似版本与相同句子仍可能跨集合。原始索引、作者、题目保存在 `*_poems.json`，原文件和固定文本的哈希见 `manifest.json`。

仅训练集建立5,408种字符，加编号0的 `<unk>`（unknown token，未知词元），词表5,409项。验证、测试未知比例约0.165%、0.147%。词表在训练集上确定，验证与测试中的未知字符统一按未知词元计分。使用UTF-8（Unicode Transformation Format, 8-bit）文本编码。

数据联合SHA-256：`3d466ed0bb33a74570694a9085f68f2119f71437039fc49aff01d62f9e3a0a07`。依训练、验证、测试顺序把集合名、零字节和原始字节送入哈希。

窗口只在同一集合内取，可跨相邻诗篇，双换行表示篇界。评价按最多32字符的不重叠输入块遍历，首字符仅作上下文，尾块保留，每个目标计一次、块间重置上下文。测试目标数142,420。模型与加一平滑二元基线使用相同目标。

课堂默认2层、4头、宽128、上下文32，参数量1,785,600。权重须与同一次训练的词表配套使用。旧小语料权重使用旧词表，保存在教师历史过拟合对照中；学生包提供当前五言子集。
