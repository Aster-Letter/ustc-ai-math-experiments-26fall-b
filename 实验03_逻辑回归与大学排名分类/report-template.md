## 一、实验目的

（可在以下目的的基础上，用自己的语言补充或改写。）

1. 理解逻辑回归将线性得分经 sigmoid 函数转换为概率、再按阈值给出类别的过程，区分得分、概率与预测类别三种输出。
2. 掌握混合类型表格数据的预处理方法，包括数值清洗与均值填补、仅由训练集拟合的标准化与独热编码，以及缺失和未见类别的处理。
3. 理解二元交叉熵损失与 L1/L2 正则化的来由，手算并用程序核对一次梯度更新，使用 PyTorch 完成小批量训练。
4. 明确训练集、验证集与测试集的职责，依据验证结果选择模型，并结合混淆矩阵、多数类基线与多项指标评价分类结果。

## 三、实验原理

简要叙述本实验所用方法的原理，篇幅建议不超过一页。公式可参考前置讲义，但须说明各符号的含义与维度。

1. **模型**：增广输入、线性得分、sigmoid 函数与阈值判别之间的关系。
2. **损失函数**：由伯努利似然推出二元交叉熵 BCE（Binary Cross-Entropy）的过程。
3. **正则化**：L1（L1 Norm，一范数）与 L2（L2 Norm，二范数）惩罚的定义（本实验的 L2 惩罚取权重平方和的一半），以及截距不受惩罚的原因。
4. **优化方法**：小批量随机梯度下降 SGD（Stochastic Gradient Descent）的参数更新公式。
5. **评价指标**：混淆矩阵中的四种计数，以及准确率、精确率、召回率和 F1 分数（F1 Score）的定义。
