# 实验03：逻辑回归与大学排名分类

主讲：胡泷；整理：胡泷、曾有成；任课教师：钟志诚。  
中国科学技术大学 人工智能与数据科学学院。

本实验使用 QS（Quacquarelli Symonds）2026 世界大学排名的整理数据，依据部分已公布的指标识别同年榜单前 500 名的学校。该任务既不预测未来排名，也不评价未上榜的大学。实验分为 C0–C7 八个检查点，共 17 处 TODO，建议用时 135 分钟。

## 数据与任务边界

源表1504行30列；学校名无重复，排名小于或等于500的学校502所（有并列）。三份分层划分为902/300/302，正类301/100/101，种子20261008。保持自然比例，不人为缺失、不重采样。源表的排名区间不跨越500，标签含义可确定；不把区间起点当作精确名次。

三个数值字段均为指标分数，不是原始比例。五个类别字段统一独热编码，训练确定类别顺序，缺失和未见类别归Unknown。只标准化数值；训练标签、名称和行号不进入特征。全部当年排名、总分、各项名次与上一年排名均排除。

同年分数仍是排名相关指标，因此这是使用部分已公布信息的分类练习，不是事前预测或因果分析。参考模型也不是现实择校建议。

## 实验报告与提交

提交文件为 `学号_姓名_lab03.zip`，其中包含 `report.pdf` 与 `code/`。报告首页注明实验名称、学号和姓名，正文按以下七个部分撰写：

1. **实验目的**：本实验需要理解和掌握的内容。
2. **实验环境与数据**：软件版本与运行设备；数据来源、划分、类别比例、真实缺失、排除字段与编码维数。
3. **实验原理**：简述模型、损失函数、正则化、优化方法与评价指标，篇幅建议不超过一页。
4. **实验内容与步骤**：C0–C7 完成情况；逐检查点给出对应函数、实现思路、3–10 行关键代码、小例子的输入与预期/实际输出及分析。C2 须覆盖数值与独热编码，C6 须包含手算更新；C0 只记录观察结果。
5. **实验结果**：训练设置、三种方案的验证结果表、冻结理由、一张损失曲线、测试指标与混淆矩阵；选做只列验证集对照。
6. **结果分析与讨论**：误报与漏判、多数类基线、至少两个验证阈值、正则化与特征选择的作用以及任务局限。
7. **实验总结**：主要结论、收获、困难与建议。

撰写时参考[报告模板](report-template.md)，采用客观、规范的书面语，图表编号并在正文中引用。仅粘贴 PASS 不能代替证据；同一图表只放一次，不要求整份代码、完整日志或安装截图；未完成的内容应如实说明。提交的代码必须能复现报告中的数值。

`code/` 保留 student、run_lab、support、workflow、checkpoints、requirements及 `data/classroom/` 三份数据、README与划分记录；采用Notebook时附logic.ipynb。无需打包教师答案、原始镜像、环境、缓存和课程讲义。输出图表放入报告，权重和预测明细可自行保留。截止日期与提交平台以课程通知为准，评分建议30%数据、40%模型、30%训练评价，不设准确率门槛。
