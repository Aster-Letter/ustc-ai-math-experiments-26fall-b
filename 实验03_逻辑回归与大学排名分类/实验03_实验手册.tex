import support

\section{C2：数值与类别分别处理}
\subsection{数值分支：三个函数}
补 \texttt{fit\_statistics}、\texttt{apply\_statistics}、\texttt{to\_tensors}。先算训练非缺失均值并填充，再算总体标准差；转换验证/测试时不重算。最后转换为浮点张量，首列加常数 1，标签成为列向量。
\begin{examplebox}[数值核对]
训练 $[1,3,\text{缺失}]$：均值 2，标准差约 0.816497；验证 100 的标准化值约 120.025。均值不会因为验证值很大而改变。常数列尺度改为 1，全空训练列均值约定为 0。
\end{examplebox}
\subsection{类别分支：两个函数}
补 \texttt{fit\_categories} 和 \texttt{encode\_categories}。前者逐列取训练中出现的非缺失值、排序，最后添加 Unknown；后者按固定类别表逐列生成 0/1 指示。缺失与未见类别统一归入 Unknown。

小例子训练取值为 Asia、Europe、缺失，列序为 Asia、Europe、Unknown；验证取值 Europe、Atlantis、缺失，预期三行分别为 $(0,1,0)$、$(0,0,1)$、$(0,0,1)$。这里 Atlantis 是用于检查未知值处理的虚构类别，不是源数据地区。
\begin{lstlisting}[language=Python]
import student
train, val, state = support.prepare_train_val(
    student, support.DATA_DIR)
print(train[0].shape, train[1].shape)
print(val[0].shape, val[1].shape)
print(state["categories"])
\end{lstlisting}
运行 \texttt{python checkpoints.py C2}。完整特征为三个标准化数值与 25 个独热列，训练输出 \texttt{(902,29)}、\texttt{(902,1)}，验证输出 \texttt{(300,29)}、\texttt{(300,1)}。新增首列常数包含在 29 中，测试文件尚未读取。

\section{C3--C4：从样本到模型}
\subsection{C3：保持特征与标签成对}
补 \file{UniversityDataset.__len__}、\texttt{\_\_getitem\_\_} 与 \texttt{make\_loader}。构造函数已保存 X 和 y；每个索引返回对应的一对张量。只在训练打乱，保留不足批量的最后一批。
\begin{lstlisting}[language=Python]
dataset = student.UniversityDataset(*train)
loader = student.make_loader(dataset, 64, True)
for X_batch, y_batch in loader:
    print(X_batch.shape, y_batch.shape)
\end{lstlisting}
运行 \texttt{python checkpoints.py C3}。五条样本、每批两条得到 $2,2,1$；真实训练 902 条、每批 64 条得到 15 批，末批 6 条。标签不单独洗牌。
\subsection{C4：线性得分和概率}
补 \texttt{sigmoid}，以及模型类的 \texttt{\_\_init\_\_}、\texttt{forward}。参数是一个列向量，行数等于增广维数，用 \texttt{nn.Parameter} 注册并零初始化。前向返回矩阵乘积；sigmoid 在概率计算时单独调用。
\begin{lstlisting}[language=Python]
model = student.LogisticRegression(train[0].shape[1])
logits = model(train[0][:3])
probabilities = student.sigmoid(logits)
print(logits.shape, probabilities)
\end{lstlisting}
运行 \texttt{python checkpoints.py C4}。参数 $(1,2,-1)^\top$、增广输入 $(1,3,2)^\top$ 的得分是 5，概率约 0.993307；不能把概率作为前向得分返回。
\begin{questionbox}[报告中记录]
C3 记录成对取样与末批；C4 记录输入、参数、得分、概率和形状。说明 \texttt{@} 与逐元素乘法 \texttt{*} 的区别。
\end{questionbox}

\section{C5--C6：目标与一次更新}
\subsection{C5：二元交叉熵和权重惩罚}
补 \texttt{data\_loss} 和 \texttt{penalty}。采用二元交叉熵 BCE（Binary Cross-Entropy），由 \texttt{BCEWith\allowbreak{}LogitsLoss} 接收原始得分并稳定计算损失。

L1（L1 Norm，一范数）惩罚为特征权重绝对值和；L2（L2 Norm，二范数）惩罚为二范数平方的一半。两者只用 \texttt{theta[1:]}，不惩罚截距。

运行 \texttt{python checkpoints.py C5}。零得分时平均交叉熵约 0.693147；参数 $(10,3,-4)$ 的两种惩罚分别为 7、12.5；L2 惩罚对截距的梯度是零。
\subsection{C6：补五步训练循环}
补 \texttt{train\_epoch}：清梯度、前向、构造数据损失加惩罚的总目标、反向传播、更新参数。SGD（Stochastic Gradient Descent，随机梯度下降）的自动微分与参数更新器已提供，学生补全连接步骤。
\begin{lstlisting}[language=Python]
optimizer.zero_grad()
logits = model(X)
loss = data_loss(logits, y)
objective = loss + strength * model.penalty(kind)
objective.backward()
optimizer.step()
\end{lstlisting}
训练时保留计算图，不能在反向前调用 \texttt{item()} 或 \texttt{detach()}。每个批次都清梯度；本函数返回的是各批更新前数据损失的加权平均，绘图另用每轮结束的完整数据损失。
\begin{examplebox}[手算再运行]
两所假设学校的增广行是 $(1,1,0)$、$(1,0,1)$，标签 1、0。零参数时概率均为 0.5，平均梯度为 $(0,-0.25,0.25)^\top$。学习率 0.4、无正则，更新为 $(0,0.1,-0.1)^\top$。详见前置讲义第 8 节。
\end{examplebox}
运行 \texttt{python checkpoints.py C6}。自检还核对第二次更新，用来发现忘记清梯度的问题。
\begin{questionbox}[报告中记录]
C5 记录损失与两种惩罚的数值；C6 记录一次手算的输入、概率、梯度、更新及代码对照。只贴“损失下降”不足以证明更新正确。
\end{questionbox}

\subsection{报告怎样解释}
列出保留/删除字段、维数、验证损失、准确率、精确率、召回率与 F1 分数（F1 Score）。如果精简后变差，说明当前规则删去了有用信息；如果相近，可讨论复杂度与可解释性的取舍。不要声称“特征越少越好”或“正则化一定提高准确率”。
\begin{pitfallbox}[两个常见混淆]
删除泄漏字段是建模前必须做的筛选，不能当成可自由调节的性能技巧。L1 惩罚鼓励稀疏，但当前普通梯度更新不保证精确零权重；不能直接把小权重视为完整字段已经被删除。
\end{pitfallbox}
\subsection{课堂追问与答案要点}
\begin{enumerate}
\item 为什么学校规模不直接设为 1、2、3、4？这样会假定相邻档位对得分的作用等距；独热编码放松该假设。
\item 为什么不按全部数据收集类别？模型表示也属于训练过程，应预先处理验证/测试中的未知类别。
\item 两个方案准确率相同，能否认为完全等价？不能，概率损失和四种计数可能不同。
\item 为什么不直接用总分？当前目标由排名构造，总分近乎直接提供目标信息。
\end{enumerate}

\section{实验报告与提交}
\subsection{四部分正文}
提交 \texttt{report.pdf}，PDF（Portable Document Format，可移植文档格式）首页列实验名称、学号、姓名。参照模板写四部分：
\begin{enumerate}
\item \textbf{实验概况。}任务与适用范围，C0--C7 完成状态，未解决问题。
\item \textbf{逐检查点实现与验证。}对应函数、思路和关键代码、小例子输入与预期/实际输出、结果解释。每项通常摘录 3--10 行关键代码，不贴整份文件；C2 同时覆盖数值与类别，C6 包含手算。
\item \textbf{综合实验结果。}来源、划分、类别比例、缺失与编码维数、训练设置、三方案验证表、测试前选择理由、一张损失曲线、最终指标和混淆矩阵。选做对照单独列验证结果。
\item \textbf{结果分析与总结。}解释误报/漏判、基线、至少两个验证阈值、正则化是否改善；说明同年分类、镜像来源、非因果与跨年泛化局限，写收获或建议。
\end{enumerate}

\subsection{提交前自查与排错}
\begin{itemize}
\item 全部 checkpoint 通过，报告中的小例子能复算。解压到其他位置后 C0 可直接运行。
\item 两个运行命令使用同一数据目录和输出目录；更换数据时使用新输出目录。
\item 维数不一致：检查未知类别是否新增列、拼接顺序是否变化、首列常数是否遗漏。
\item 损失异常：检查数值缺失、尺度、重复 sigmoid、学习率以及反向前切断计算图。
\item 第二次手算不一致：检查每批是否清梯度。
\item 训练总目标与曲线不同：曲线是无正则数据损失，不是带惩罚的目标。
\item 测试很高不代表任务正确：先核对是否混入排名、总分或排序行号。
\end{itemize}
\subsection{参考运行与解释}
本环境固定划分与设置下，三组均在第 60 轮取得各自最低验证损失，无正则约 0.371792，L2 约 0.379552，L1 约 0.392744，三组验证准确率均 0.83。故主实验选择无正则，而非预设正则化一定更好。

冻结后一次测试：准确率 84.11\%、精确率 81.18\%、召回率 68.32\%、F1 约 0.7419；混淆矩阵为真负例 185、假正例 16、假负例 32、真正例 69。多数类基线为 66.56\%。这是本次数据的实际运行，不是教材结果或未来年份效果。
