# 任务二：鸢尾花数据观察与分类

> 完成 [iris_classification.py](iris_classification.py) 中的 `LAB01_TODO I1–I3`，通过[调用检查](check_iris.py)，再运行程序查看训练与预测结果。环境安装见[实验手册](../../实验01_实验手册.md)。

## 项目目标

如果知道一朵花的花萼和花瓣尺寸，能否判断它属于哪个品种？本项目使用一份带有品种标签的鸢尾花数据，调用现成的决策树模型完成一次简单分类。

你需要辨认训练与预测所需的数据，补全调用，让同一个模型先学习、再预测，并核对实际结果。本次不要求自行实现分类算法，也不要求调整参数追求更高准确率。

## 数据从哪里来

数据由 scikit-learn 自带的 [Iris 数据集](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html)提供，代码使用 `load_iris()` 加载。安装依赖后，无需另外下载数据文件。

这里处理的是数值测量记录，不是花朵照片。每行代表一朵花，四列依次为：

| 列编号 | 特征 | 单位 |
| --- | --- | --- |
| 0 | 花萼长度（sepal length） | cm |
| 1 | 花萼宽度（sepal width） | cm |
| 2 | 花瓣长度（petal length） | cm |
| 3 | 花瓣宽度（petal width） | cm |

全部 150 个样本分属 setosa、versicolor、virginica 三个品种，每类 50 个。标签 `0`、`1`、`2` 是品种编号，不表示等级。

数据本身没有预先分好的训练文件和测试文件。框架使用 `train_test_split` 从中划分：

| 数据 | 特征形状 | 标签形状 | 每个品种的样本数 |
| --- | --- | --- | --- |
| 训练集 | `(120, 4)` | `(120,)` | 40 |
| 测试集 | `(30, 4)` | `(30,)` | 10 |

划分参数固定为 `test_size=0.2`、`random_state=42`，并使用 `stratify` 保持类别比例。特征与标签一起划分，因此同一位置始终对应同一朵花。相关读取和划分代码已提供，请保留。[接口说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.train_test_split.html)

## 第一步：辨认数据与调用关系

先阅读主流程，找到四个变量：

| 变量 | 含义 | 用在什么地方 |
| --- | --- | --- |
| `X_train` | 训练花的四项测量值 | 训练模型、观察训练数据 |
| `y_train` | 这些训练花的真实品种 | 训练模型 |
| `X_test` | 测试花的四项测量值 | 交给训练好的模型预测 |
| `y_test` | 测试花的真实品种 | 在预测完成后评价结果 |

整个流程是：

```text
加载数据并划分（已提供）
    ├── X_train、y_train → 训练集散点图（I1 选择两列）
    └── X_train、y_train → model.fit(...)（I2）
                               ↓ 同一个训练好的 model
                         X_test → model.predict(...)（I3）
                                          ↓ predictions
                            与 y_test 比较 → 准确率、混淆矩阵（已提供）
```

预测函数不需要真实测试标签。框架把 `y_test` 留在评价部分，便于看清“预测结果”和“正确答案”分别来自哪里。阅读这段流程后即可开始补全，不需要另写一份变量解释报告。

### I3：让同一个模型预测

接着补全 I3，调用刚训练好的模型的 `predict` 方法，把结果保存为变量 `predictions`：

```text

```

每个测试样本对应一个预测品种编号。预测时使用测试特征，不能传入真实测试标签，也无需再次训练。末尾的 `return model, predictions` 已提供，无需改写。

这里的关键是接对数据和对象：训练与预测使用同一个模型，预测结果留给后面的评价代码使用。

### 4.3 怎样核对评价结果

准确率是预测正确的样本比例。例如 30 个测试样本中有 27 个预测正确，准确率就是 `27 / 30 = 0.9`。这是解释指标的例子，不是作业目标值。

混淆矩阵的行表示真实品种，列表示预测品种，顺序均为 setosa、versicolor、virginica。下面是假设的 6 个样本结果：

```text
                 预测 0  预测 1  预测 2
真实 0              2       0       0
真实 1              0       1       1
真实 2              0       0       2
```

真实类别 1、预测类别 2 的位置为 1，表示一朵 versicolor 被预测为 virginica。对角线上共有 5 个样本，表示预测正确 5 次。

对自己的结果核对：矩阵所有格子相加应为 30，对角线之和除以 30 应等于显示的准确率。这两个量的对应关系由验证程序检查，也可以用实际输出直接确认。
