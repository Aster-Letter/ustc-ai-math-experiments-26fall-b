# 图像分类项目协作约定

- 先读 README.md、当前配置、提交脚本与用户提供的实际日志。
- 本地 agent 修改本地项目；平台执行结果来自学生取回的日志和目录信息。
- 优先使用已核验的环境、分区和资源范围，只改当前任务所需部分。
- 路径排错先核对作业工作目录、data-dir 和目录结构，不凭本地路径猜测远端文件已存在。
- CUDA 不可用时保留明确报错；不要改成静默 CPU 回退，也不要把 CPU 输出称作 GPU 验证。
- 不覆盖已有运行结果；为新配置使用新的 output 目录，保留种子与配置记录。
- 输出修订说明、文件差异和重跑命令；平台尚未执行的部分明确标注待验证。
