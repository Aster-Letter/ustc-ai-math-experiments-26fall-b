# 实验04：AI Harness 工具配置及107本科生算力平台介绍

主讲：史睿铭；整理：史睿铭、曾有成；任课教师：钟志诚。
中国科学技术大学 人工智能与数据科学学院。

本实验学习两类工具如何配合完成项目：AI Harness 在本地组织模型与工具，协助读取代码、修改程序和运行检查；107本科生算力平台提供远程 CPU/GPU 资源，运行你提交的计算任务。

通过实验02的决策树代码和一个图像分类项目，你会经历“提出要求 → 读取与修改 → 运行并检查 → 根据结果继续推进”的过程，并认识本地编辑、模型 API 调用与远程训练各自发生在哪里。

本实验供自主学习，不要求提交代码、截图、结果或报告，不计入评分；但相关内容的学习对后续实验与大作业的效率有较大的提升，建议学习或后续必要时参考。

**快速入口**：[如何开始](#如何开始) · [实验讲义](实验04_实验讲义.md) · [PDF](实验04_实验讲义.pdf) · [安装演示视频](https://www.bilibili.com/video/BV19R3X6vEMQ)。平台部分使用图文讲义与配套代码。

## 实验内容

### 第一部分：配置 AI 工具，完成一次代码协作

先从网页聊天过渡到工具协作，浅看 Transformer 如何生成内容，分清模型、API 服务与 Harness 的作用，以及模型调用怎样计费。随后在 Windows 上配置 Codex + DeepSeek，尝试文字问答、文件读取和 Python 执行；学校提供的 API 资源与其他入口在讲义中另有说明。

配套[决策树协作练习](code/decision-tree-practice/README.md)复用实验02的初始骨架。A 阶段只完成 T1 信息熵，观察 Agent 怎样读取、修改和检查；B 阶段把任务扩展到 T2–T7，运行完整自查。重点是说清任务范围、看懂实际改动和执行结果，使用本实验副本即可保留自己原先的实验02代码。

### 第二部分：在107平台运行 CPU/GPU 任务

配套[平台实践项目](code/compute-practice/README.md)先用一个 CPU 小程序学习上传、提交任务、查看日志和下载结果，再运行 CIFAR-10 + ResNet-18 短训练。CIFAR-10 是十类小图像数据，ResNet-18 是本练习使用的图像分类网络；训练代码已提供，主线采用少样本、少步数配置。

你会分步配置独立环境、准备数据、用 sbatch 提交 GPU 任务，再取回模型、指标和日志，确认任务与临时应用结束。本地 Agent 协助修改项目与脚本，平台上的执行由你完成；遇到问题时，可带回日志继续请 Agent 排查。

扩展内容集中在附录：[较大训练与项目迁移](实验04_实验讲义.md#migration)、[配置管理器和工具扩展](实验04_实验讲义.md#sec-11)、[DSH 条件与配置](实验04_实验讲义.md#dsh)。完成主线后可按需要阅读，主线中的路径排错演示也可选做。

## 开始前准备

- **本地电脑与 Python**：以 Windows 为主。决策树沿用实验01/02的 `ustc-ai-experiments-26fall-B`（Python 3.11），只使用标准库；需要复习 Python 时先看实验02的语法带练。
- **模型服务**：准备可用的 API Key。主线使用 DeepSeek 官方按量计费服务，申请与费用见[本地配置章](实验04_实验讲义.md#harness-setup)；校园 API 资源见[学校 API 说明](实验04_实验讲义.md#sec-10)。
- **平台访问**：进入平台部分时，访问 [107平台](https://107.ustc.edu.cn/)，通过统一身份认证登录并确认自己的资源权限。GPU 环境和 CIFAR-10 数据按平台章节另行准备，保留原先的课程基础环境。

## 如何开始

1. 在课程仓库首页“实验04”一行下载学生材料包，完整解压。本说明、讲义、配图、两个项目和排版源都在同一个包内。
2. 打开讲义，从[基础认识](实验04_实验讲义.md#harness-basics)开始；按[Windows 配置章](实验04_实验讲义.md#harness-setup)或安装视频完成连接。
3. 复制 `code/decision-tree-practice/` 到自己的练习位置，按[项目说明](code/decision-tree-practice/README.md)准备课程解释器，再做 A→B 协作。
4. 进入 `code/compute-practice/`，先按[CPU 入门](实验04_实验讲义.md#platform-cpu)提交第一个小任务，再继续 GPU 短训练和结果管理。
