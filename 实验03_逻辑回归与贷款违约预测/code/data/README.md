# 天池贷款数据与课堂划分

本实验已切换为用户于 2026-10-08 从阿里云天池下载的真实贷款数据。课堂文件由带标签的 `train.csv` 重新抽样，不是模拟数据，也不能声称与旧教材的 1 万条子集完全相同。

## 默认课堂数据：classroom/

仅从上述带标签训练文件无放回抽取课堂数据。先用 NumPy 种子 `20261008` 重建原来约 19.95% 正类的 8000/1000/1000 划分，保留验证、测试文件逐字节不变。按指导书要求将训练正类比例调整为 50%：保留原训练表前 4000 条负类与全部 1596 条正类，从原三份数据之外随机补入 2404 条正类，再打乱训练表；补充和打乱使用种子 `20261009`。不重复样本，不按预测难度筛选记录。这是针对上一版低召回率所做的教学修订，不能表述为在查看测试结果前预先设计的对比。

| 课堂文件 | 行数 | 正类数 | 缺失标签 | 八个输入字段中的缺失情况 |
| --- | ---: | ---: | ---: | --- |
| `classroom/train.csv` | 8000 | 4000 | 0 | 就业年限 503 条；dti 1 条 |
| `classroom/val.csv` | 1000 | 200 | 0 | 就业年限 48 条 |
| `classroom/test.csv` | 1000 | 200 | 0 | 就业年限 70 条；dti 1 条 |

保留原始 47 列和 `id`；三份编号互斥。模型仅使用下面的八个字段，常数列加入后是 9 维。训练集正负各半，验证与测试仍各含 20% 正类。标签不人工挖空；缺失标签处理仍通过 C1 的小例子练习。`classroom/split_manifest.json` 保存原文件与三份文件摘要、随机种子、版本、规模和字段。数据划分时可按标签分层，但模型训练、参数选择不得使用测试标签；运行程序只在最终评价阶段读取课堂测试文件。

教师可在实验目录执行 `python teacher/prepare_classroom_data.py`，从本地原始文件重建同一划分。学生直接使用随包课堂文件，无需下载原始数据或运行抽样脚本。

## 字段与预处理约定

| 字段 | 含义 / 处理 |
| --- | --- |
| `loanAmnt` | 贷款金额，保留源数据数值；未核实币种，不标注为人民币元 |
| `interestRate` | 利率原始百分数值，例如 12 表示 12% |
| `annualIncome` | 年收入，保留源数据数值；未核实币种 |
| `dti` | 债务收入比，保留原字段和尺度，不改名为旧模拟字段 `debtRatio`，不除以 100，也不裁剪到 0–1 |
| `grade` | A–G 映射为 1–7，这是有序等距编码的教学简化 |
| `employmentLength` | `< 1 year→1`、`1 year→2`、`10+ years→12`，普通整数年限加 1；缺失保留 |
| `issueDate` | YYYY-MM-DD，距训练集最早日期的天数 |
| `earliesCreditLine` | 英文月份缩写-年份，距训练集最早信用月份的月数；保留源字段拼写 |
| `id`、其他列 | 保留追溯和扩展用途，本次不进入模型 |
| `isDefault` | 真实标签 0/1，1 表示违约；不填充、不标准化 |

CSV（Comma-Separated Values，逗号分隔值）空字段表示缺失。缺失填充值、日期原点和标准化参数只由训练集拟合，验证和测试复用。标准差采用填充后的总体标准差；零尺度改为 1、全空训练列均值约定为 0。保留数据中的极端值，不根据测试表现决定删除或截断；原始 dti 范围为 -1 至 999，其异常含义未经确认，是本实验的数据质量局限。

平衡训练改变了类别先验，未经校准的输出不能直接当作自然人群违约概率；阈值 0.5 是课堂固定决策规则。训练与验证类别比例不同，不能只凭两条损失曲线的高低差断言过拟合。此轮复用了已查看过的测试集，只作教学对照；若要严谨比较改进后的泛化能力，应另外预留未见数据。随机划分只能评价同一来源下的留出表现，不能证明跨时间、跨人群泛化。等级、利率和发放日期在实际预测时是否可得，须按业务时点另行核对。本实验不是实际授信决策系统。

## 与旧模拟版本的关系

旧模拟三份数据与说明已归档到教师目录 `teacher/mock-data/`，旧参考结果在 `teacher/mock-reference/`，默认代码和学生包均不使用它们。`generate_demo_data.py` 现在仅输出到该归档目录，不会覆盖用户下载的原始 `train.csv`。课堂手算的两条样本仍为专门构造，与真实数据的原编号无对应关系。

默认入口读取 `data/classroom/`。自备划分时通过 `--data-dir` 指向含 train/val/test 的独立目录，必须含八个约定字段与真实标签；新的数据使用新的输出目录。扩展特征须逐列核对类型与可用时点。
